# 💫 About Me:
Olá, eu sou o Rodrigo.<br>Sou um programador movido pela curiosidade e pelo desafio de dominar novas tecnologias. Meu foco não está em uma única linguagem, mas sim na resolução de problemas complexos através do código — seja explorando as camadas mais profundas da cybersegurança e análise de malware, ou construindo softwares robustos e aplicações web modernas.<br><br>Para mim, programar é um processo de aprendizado contínuo. Independentemente da plataforma, meu objetivo é entender como as coisas funcionam por dentro para fazê-las funcionar melhor por fora.
